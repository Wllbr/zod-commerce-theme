# Product Type Switcher v1.6.32

## What changed
- Complete compact redesign based on the approved ZOD mockup: title, six icon tabs, slim media banner, then the product shelf.
- Up to six type options, each mapped to one Salla category, with optional manual product override up to 36 products.
- Each option can upload its own custom 128×128 transparent icon displayed beside the option label.
- Banner supports either a direct MP4/WebM video URL or responsive image backgrounds. Video takes priority and images act as poster/fallback.
- Optional transparent product cutout pops into the banner on category change.
- Arabic keeps copy on the right and visual on the left; English naturally mirrors to copy-left / visual-right.
- Mobile type tabs are horizontally swipeable; product shelf keeps the existing auto-advance behavior and pauses after user interaction.
- Banner video pauses when hidden/off-screen and respects reduced-motion preferences.
- Desktop containers widen to 1600px on large screens, with slightly tighter section density, creating the requested more-open “zoomed-out” desktop feel without forcing browser zoom.

## Media guidance shown in the Salla editor
- Type icon: 128×128 PNG/WebP, transparent, <100KB preferred.
- Desktop banner image/poster: 1600×300 JPG/WebP, <700KB preferred.
- Mobile banner image: 1080×420 JPG/WebP, <500KB preferred.
- Banner video: direct HTTPS MP4/WebM, ~1600×300 ratio, 4–8 second seamless loop, no audio, <3MB preferred.
- Desktop popup product cutout: 900×900 transparent PNG/WebP, <450KB preferred.
- Mobile popup product cutout: 700×700 transparent PNG/WebP, <350KB preferred.
