# Product Type Switcher — v1.6.16

Add **Product type switcher / منتجات حسب النوع** from the Salla home-page component editor.

For each product type:

1. Enter its Arabic and English name.
2. Select one category to populate products automatically.
3. Optionally select specific products; these take priority over the category products.
4. Optionally choose a custom “Browse all” link; otherwise the category link is used.

The section accepts 2–8 product types and up to 12 manually selected products per type. It can be reused for ventilation, intercoms, batteries, extensions, insect traps, accessories, or any other department.

The soft-neutral background is enabled by default and can be disabled in the component settings. Tabs follow the storefront direction, scroll horizontally on mobile, support keyboard navigation, and lazy-mount inactive product groups.
