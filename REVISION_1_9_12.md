# ZOD Commerce 1.9.12 — desktop cart checkout placement

Review candidate, 22 September 2026. Not published live.

- On desktop widths, the one native Salla checkout action now sits directly below the order totals inside the summary card.
- Removed the desktop fixed bottom positioning and the extra page-bottom space it required.
- Mobile behavior is unchanged: the native checkout remains fixed above the persistent five-item mobile navigation.
- All optional Salla-hosted media, slider behavior, approval fixes and the strict 1,000,000-byte archive limit from 1.9.11 remain in place.
