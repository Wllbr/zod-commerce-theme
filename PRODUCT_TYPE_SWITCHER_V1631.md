# Product type switcher — v1.6.31

The universal Product Type Switcher is now a compact six-option showcase instead of a boxed tab strip.

- Up to 6 single-select product types.
- Each type maps to exactly one category, with an optional manual override of up to 36 products.
- A responsive micro-banner changes with the active type.
- Banner copy is multilingual and automatically follows RTL/LTR direction.
- Optional responsive background and transparent product cutout images are supported per type.
- The product cutout uses a restrained pop/fade animation and the banner background uses a slow drift animation when motion is allowed.
- Mobile product sliders auto-advance every 4.4 seconds, pause after user interaction, stop when the tab is hidden, and respect reduced-motion preferences.
- Product slider rendering remains Salla-native with the ZOD custom product card.

## Image guidance

- Desktop popup product: 1000×1000 px, transparent PNG preferred, ideally under 500 KB.
- Mobile popup product: 800×800 px, transparent PNG preferred, ideally under 400 KB.
- Desktop banner background: 1600×420 px, JPG/WebP preferred, ideally under 800 KB.
- Mobile banner background: 1080×540 px, JPG/WebP preferred, ideally under 500 KB.
- Do not bake text, buttons, or pricing into banner images; the theme renders localized content separately.
